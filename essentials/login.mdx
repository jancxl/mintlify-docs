# Logging in

https://portal.vouchconcierge.com/web

**Username** → Email Address 

**Password** → Generic Password 

*Password will be prompted to change upon initial login*


# Merchant Profile Set up
Once logged in, scroll down and locate the following: Settings > Profile

Under Profile -> to take note of the following: 

Merchant Code - 4 Alphabets [Usually they are the acronym of the Hotel name]

Example: Hotel Demo = HTDM

This will always be  predetermined  by the PO lead, upon creation and will not be able to change

Should there be any special prefix please inform in advance before creation

Company Name -> Hotel Name

Merchant Landing Page -> To be updated once the landing page is created

Example: https://app.vouchconcierge.com/janhotel/homepage?vcuser_room_number=TEST

*Creation of landing page; to refer to this [link]()*

**Timezone** -> To be set up base on the country of the hotel

Example: Asia/Singapore or Asia/Bangkok

Currency -> Update base on local currency

Example: SGD / THB / IDR / MYR

Once these have been updated, save the page.
